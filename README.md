# 10.Implemetation-of-wave-generator-using-ICL8038-Function-generator-IC
**Aim:**
To Simulate Triangular-wave-generator using Op-amp

**SOFTWARE REQUIRED:**
 Proteus

**PROCEDURE:**
 1.Open Proteus software and create a new project. 2.Open the Schematic Capture window. 3.Select and place all the required components from the component library. 4.Connect the components according to the given circuit diagram. 5.Check the circuit connections carefully, including VCC, GND, and input/output connections. 6.Set the required power supply and component values. 7. an oscilloscope at the output to observe the waveform. 8.Run the simulation by clicking the Run/Play button. 9.Observe the output waveform on the oscilloscope. 10.If required, measure the amplitude and frequency of the output waveform. 11.Stop the simulation after obtaining the required waveform. 12.Record the observed waveform and compare it with the expected waveform.
